# Contributing

Keep the default workflow dependency-free and reproducible. Start by running the unittest suite and a small CLI run. For a policy change, add an invariant or edge-case test and compare against the same demand paths; retain results where the new policy loses.

Do not commit real customer data, credentials, generated SQLite databases, or unexplained performance claims. Disclose assumptions and licenses for any new data source. A new external dependency requires a clear benefit, license review, and pinned/reviewed installation plan.

Submit focused changes with: the business question, method, tests, limitations, and the exact command needed to reproduce results. All accepted code contributions use this repository's MIT license.
